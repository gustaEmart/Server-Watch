Guia de instalacao

Windows
  1. Baixe o instalador Windows do Probe Collector.
  2. Execute o arquivo como administrador e informe a URL abaixo, ID, nome e token.
  3. Ao concluir, o servidor aparece automaticamente em Probes e pode ser vinculado ao cadastro.
http://sw.grupoinsideti.com.br:3000
Linux ou Proxmox
  1. Copie o comando abaixo.
  2. Execute no terminal do servidor que sera monitorado.
  3. Use o seletor Linux/Proxmox da tela principal quando precisar trocar o modo do comando.
Windows
  1. Baixe o instalador Windows do LinkProbe.
  2. Cadastre 2 a 10 links, preenchendo nome, IP a pingar, gateway e mascara.
  3. O instalador cria uma tarefa por link e registra os links no ServerWatch.
http://sw.grupoinsideti.com.br:3000
Linux
  1. Copie o comando abaixo e ajuste agent-id, nome e alvos.
  2. Instale uma instancia por link/WAN.
  3. Garanta no firewall que cada alvo saia pelo gateway correto.
RouterOS direto na RB
  1. Copie o comando RouterOS da area de downloads.
  2. Troque agentId, deviceName e a lista de uplinks no formato Nome|interface|gateway|prefixo|alvoTeste.
  3. Preencha groupName no comando se quiser que a empresa seja criada/vinculada automaticamente.
  4. Cole no terminal da RB. O script cria um scheduler e envia os links para o ServerWatch.
Nome|interface|gateway|prefixo|alvoTeste;Nome 2|interface2|gateway2|prefixo|alvoTeste2
Comando base
  1. Use quando nao houver computador ou servidor para rodar agente local.
  2. O status online exige interface ativa e ping no alvo de teste via gateway desse link.
  3. A rota ativa vem da tabela de rotas do MikroTik.
  4. Se um uplink cair, a RB reporta pelo link que continuar online.
